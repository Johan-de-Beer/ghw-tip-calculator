# Tip Calculator — MLH Global Hack Week: Build a Mini App with Cursor

I built a small tip calculator web app with Vite and TypeScript that takes a bill amount, a preset (10/15/20%) or custom tip percentage, and the number of people, then shows the tip total, the overall total, and the amount per person, with input validation. It was created in my Cursor-powered Grok Bot workspace, where the AI agent scaffolded the Vite + TypeScript project, wrote the calculator logic and UI, and checked that the build passed and the running app worked.

## Run locally

```bash
npm install
npm run dev
```
